# Changelog

## v0.8

- Добавлена отдельная вкладка «Камни».
- Камни читаются из активного SkillSet PoB XML и группируются по слотам/связкам.
- Для каждого камня используются точные уровень и качество из XML.
- Поиск камня делает один запрос PoE Trade: точное название, уровень и качество.
- Допуск по роллам применяется только к шмоту.
- Повторный поиск той же позиции использует кэш.
- Умения, выдаваемые предметом и не являющиеся покупаемыми камнями, не попадают в список.
- Добавлена локальная защита от rate limit: 4/10с, 13/60с, 27/300с.
- При HTTP 429 сохраняется Retry-After; перезапуск приложения не сбрасывает паузу.
- Forbidden Flame / Forbidden Flesh обрабатываются как option-stat с конкретным Ascendancy notable.
