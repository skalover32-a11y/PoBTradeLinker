# PoB Trade Linker

**PoB Trade Linker** — небольшая Windows-утилита для Path of Exile 1, которая читает XML из Path of Building / LootKeeper и по клику строит готовый поиск на официальном PoE Trade.

Главная идея: **не отправлять десятки запросов сразу**. Вы выбираете конкретный слот или камень — программа делает один поиск и открывает результат в браузере.

> Текущая версия: **v0.8**  
> Платформа: **Windows 10/11**  
> Требования: **Windows PowerShell 5.1+**  
> Python, установка зависимостей и POESESSID **не нужны**.

## Возможности

### Шмот

- Читает активный `ItemSet` из PoB XML.
- Показывает экипированные предметы, фласки, самоцветы и кластеры.
- По клику **«Открыть»** формирует поиск на официальном PoE Trade.
- Для редких предметов выбирает наиболее важные моды и применяет настраиваемый допуск по роллам.
- Учитывает уникальные/реликтовые предметы, corrupted implicits, mutated-моды, кластеры и ряд специальных случаев.
- Отдельно обрабатывает **Forbidden Flame / Forbidden Flesh** и не отправляет бессмысленный поиск по всем Forbidden-самоцветам, если нужный Ascendancy-мод не удалось определить.
- Повторный клик по уже найденной позиции использует кэш и не делает новый search-запрос.

### Камни

- Отдельная вкладка **«Камни»**.
- Читает камни из активного `SkillSet` PoB.
- Группирует их по слотам и связкам.
- Ищет **точное название, точный уровень и точное качество** из XML.
- Поддерживает трансфигурированные камни.
- Умения, которые выдаёт сам предмет и которые не являются покупаемыми гемами, пропускаются.
- Допуск по роллам шмота к камням не применяется.

## Защита от rate limit

PoE Trade ограничивает частоту запросов. Поэтому PoB Trade Linker намеренно работает по принципу **один клик → один search-запрос** и хранит локальное состояние лимита в `rate_limit_state.json`.

Локальный предохранитель v0.8:

- до 4 поисков за 10 секунд;
- до 13 поисков за 60 секунд;
- до 27 поисков за 300 секунд.

Если сервер возвращает HTTP 429, программа сохраняет `Retry-After` и блокирует новые API-запросы до окончания паузы. Перезапуск приложения этот таймер не сбрасывает.

> Ручные поиски в браузере могут расходовать тот же IP-бюджет, поэтому лимиты программы специально оставляют запас.

## Запуск

1. Скачайте файлы репозитория или архив релиза.
2. Положите `START.cmd` и `PoBTradeLinker.ps1` в одну папку.
3. Запустите `START.cmd`.
4. Выберите XML, экспортированный из Path of Building / LootKeeper.
5. На вкладке **«Шмот»** или **«Камни»** нажмите **«Открыть»** напротив нужной позиции.

`START.cmd` запускает PowerShell с `-ExecutionPolicy Bypass` только для этого процесса; системная политика PowerShell не изменяется.

## Как работает поиск

Для шмота программа сопоставляет моды из PoB XML со справочником официального Trade API, формирует JSON-запрос и открывает полученный search ID в браузере. Допуск по роллам задаётся в интерфейсе; по умолчанию — **15%**.

Для камней формируется отдельный точный запрос: тип камня + `level min=max` + `quality min=max`.

## Приватность

PoB Trade Linker:

- не просит логин или пароль Path of Exile;
- не использует `POESESSID`;
- не читает cookies браузера;
- не выполняет массовый автоматический поиск;
- отправляет запросы только после действия пользователя.

## Файлы

- `PoBTradeLinker.ps1` — приложение и вся логика.
- `START.cmd` — простой запуск для Windows.
- `rate_limit_state.json` — создаётся автоматически рядом со скриптом и не должен коммититься в Git.
